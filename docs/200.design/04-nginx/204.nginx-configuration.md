# Phase 204 — Nginx Configuration

## Overview
This document defines the complete nginx configuration for load balancing across generator instances, including health checks, timeouts, and security settings.

## Configuration Files

### Main Configuration

```nginx
# /etc/nginx/nginx.conf
worker_processes auto;
error_log /var/log/nginx/error.log warn;
pid /var/run/nginx.pid;

events {
    worker_connections 1024;
    use epoll;
    multi_accept on;
}

http {
    include /etc/nginx/mime.types;
    default_type application/octet-stream;

    # Logging format
    log_format main '$remote_addr - $remote_user [$time_local] "$request" '
                    '$status $body_bytes_sent "$http_referer" '
                    '"$http_user_agent" "$http_x_forwarded_for" '
                    'rt=$request_time uct="$upstream_connect_time" '
                    'uht="$upstream_header_time" urt="$upstream_response_time"';

    access_log /var/log/nginx/access.log main;

    # Performance
    sendfile on;
    tcp_nopush on;
    tcp_nodelay on;
    keepalive_timeout 65;
    types_hash_max_size 2048;

    # Security
    server_tokens off;

    # Gzip compression
    gzip on;
    gzip_vary on;
    gzip_proxied any;
    gzip_comp_level 6;
    gzip_types text/plain application/json application/javascript;

    # Rate limiting
    limit_req_zone $binary_remote_addr zone=api:10m rate=10000r/s;

    # Upstream configuration
    upstream generators {
        least_conn;

        server generator-1:5001 max_fails=3 fail_timeout=30s;
        server generator-2:5002 max_fails=3 fail_timeout=30s;
        server generator-3:5003 max_fails=3 fail_timeout=30s;

        keepalive 32;
    }

    # Include site configurations
    include /etc/nginx/conf.d/*.conf;
}
```

### Site Configuration

```nginx
# /etc/nginx/conf.d/default.conf
server {
    listen 80;
    server_name _;

    # Rate limiting
    limit_req zone=api burst=1000 nodelay;

    # Proxy settings
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Correlation-ID $http_x_correlation_id;
    proxy_set_header Connection "";

    # Timeouts
    proxy_connect_timeout 5s;
    proxy_send_timeout 10s;
    proxy_read_timeout 10s;

    # Buffers
    proxy_buffering off;
    proxy_buffer_size 4k;
    proxy_buffers 8 4k;

    # Main location - /generate
    location / {
        proxy_pass http://generators;
        proxy_next_upstream error timeout invalid_header http_500;
        proxy_next_upstream_tries 3;
    }

    # Health check endpoint (bypasses rate limiting)
    location /health {
        proxy_pass http://generators;
        proxy_connect_timeout 2s;
        proxy_read_timeout 2s;

        # Allow without rate limiting
        limit_req off;
    }

    # Metrics endpoint
    location /metrics {
        proxy_pass http://generators;
        proxy_connect_timeout 2s;
        proxy_read_timeout 5s;
    }

    # Health check page (for nginx itself)
    location /nginx_health {
        access_log off;
        return 200 "nginx OK\n";
        add_header Content-Type text/plain;
    }
}
```

## Health Check Configuration

### Passive Health Checks

```nginx
upstream generators {
    least_conn;

    # max_fails: Number of failures before removing
    # fail_timeout: How long to mark as failed
    server generator-1:5001 max_fails=3 fail_timeout=30s;
    server generator-2:5002 max_fails=3 fail_timeout=30s;
    server generator-3:5003 max_fails=3 fail_timeout=30s;
}
```

### Health Check Behavior

| Event | Behavior |
|-------|----------|
| Connection timeout | Mark as failed |
| Connection refused | Mark as failed |
| HTTP 500 response | Mark as failed |
| 3 failures in 30s | Remove from pool |
| After 30s | Retry the failed server |

### Active Health Checks (Optional)

```nginx
# Requires nginx plus or open source with health check module
upstream generators {
    least_conn;

    server generator-1:5001;
    server generator-2:5002;
    server generator-3:5003;

    health_check type=http uri=/health interval=5s fails=2 passes=2;
}
```

## Timeout Configuration

### Timeout Values

| Timeout | Value | Rationale |
|---------|-------|-----------|
| proxy_connect_timeout | 5s | Initial connection to upstream |
| proxy_send_timeout | 10s | Time to send request |
| proxy_read_timeout | 10s | Time to read response |
| keepalive_timeout | 65s | Idle keepalive |
| keepalive_requests | 1000 | Max requests per connection |

### Timeout Matrix

```
Client timeout: 5s (configurable)
  │
  ├─ nginx proxy_read_timeout: 10s
  │     │
  │     └─ Generator processing: ~1ms
  │           │
  │           └─ Response returned
  │
  └─ If no response in 5s: Return 504 Gateway Timeout
```

## Load Balancing Algorithm

### least_conn (Chosen)

```nginx
upstream generators {
    least_conn;  # Routes to server with fewest active connections
    server generator-1:5001;
    server generator-2:5002;
    server generator-3:5003;
}
```

### Algorithm Comparison

| Algorithm | Description | Use Case |
|----------|-------------|----------|
| round_robin | Cyclic distribution | Simple, even distribution |
| least_conn | Fewest active connections | Best for varying request times |
| ip_hash | Consistent hashing by IP | Session affinity |
| hash | Custom hash | Key-based routing |

**Decision:** `least_conn` chosen for best performance with varying request times.

## Circuit Breaker Pattern

```nginx
# If all generators fail, return 503 immediately
proxy_next_upstream error timeout;
proxy_next_upstream_tries 3;

# Custom error page for upstream failures
error_page 502 503 504 /50x.html;
location = /50x.html {
    root /usr/share/nginx/html;
    internal;
}
```

### Error Response When All Upstream Down

```json
{
  "error": "No generators available",
  "code": "GENERATORS_UNAVAILABLE"
}
```

## Security Configuration

### Security Headers

```nginx
server {
    # Remove nginx version
    server_tokens off;

    # Security headers (for API responses)
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;
    add_header Referrer-Policy "no-referrer" always;
}
```

### Connection Limits

```nginx
# Per IP connection limit
limit_conn_zone $binary_remote_addr zone=conn_limit:10m;
limit_conn conn_limit 100;

# Per server connection limit
limit_conn_zone $server_name zone=server_limit:10m;
```

## Docker Configuration

### Dockerfile

```dockerfile
FROM nginx:alpine

# Copy configuration
COPY nginx.conf /etc/nginx/nginx.conf
COPY conf.d /etc/nginx/conf.d/

# Expose port
EXPOSE 80

# Health check
HEALTHCHECK --interval=5s --timeout=3s --start-period=5s --retries=3 \
    CMD wget --no-verbose --tries=1 --spider http://localhost/nginx_health || exit 1

CMD ["nginx", "-g", "daemon off;"]
```

### Volume Mounts

```yaml
# docker-compose.yaml
nginx:
  build: ./nginx
  ports:
    - "80:80"
  volumes:
    - ./nginx/nginx.conf:/etc/nginx/nginx.conf:ro
    - ./nginx/conf.d:/etc/nginx/conf.d:ro
  depends_on:
    - generator-1
    - generator-2
    - generator-3
  healthcheck:
    test: ["CMD", "wget", "--no-verbose", "--tries=1", "--spider", "http://localhost/nginx_health"]
    interval: 5s
    timeout: 3s
    retries: 3
```
