# Phase 205 — Deployment Specifications

## Overview
This document defines the Docker containerization, docker-compose configuration, and environment variables for deploying the Unique ID Generator service.

## Docker Images

### Generator Service

```dockerfile
# generator/Dockerfile
FROM python:3.11-slim AS builder

WORKDIR /app
RUN pip install --no-cache-dir poetry

COPY pyproject.toml poetry.lock* ./
RUN poetry export --without-hashes -f requirements.txt --output requirements.txt \
    && pip install --no-cache-dir -r requirements.txt

FROM python:3.11-slim

WORKDIR /app

# Create non-root user
RUN useradd --create-home --shell /bin/bash appuser

# Copy virtualenv from builder
COPY --from=builder /usr/local/lib/python3.11/site-packages /usr/local/lib/python3.11/site-packages
COPY --from=builder /usr/local/bin /usr/local/bin

# Copy application
COPY --chown=appuser:appuser . /home/appuser
WORKDIR /home/appuser

# Environment variables
ENV PYTHONUNBUFFERED=1
ENV PYTHONDONTWRITEBYTECODE=1

# Expose port
EXPOSE 5001

# Health check
HEALTHCHECK --interval=10s --timeout=5s --start-period=5s --retries=3 \
    CMD python -c "import urllib.request; urllib.request.urlopen('http://localhost:5001/health')"

USER appuser

CMD ["python", "-m", "generator.main"]
```

### nginx

```dockerfile
# nginx/Dockerfile
FROM nginx:alpine

COPY nginx.conf /etc/nginx/nginx.conf
COPY conf.d /etc/nginx/conf.d/

EXPOSE 80

HEALTHCHECK --interval=5s --timeout=3s --start-period=5s --retries=3 \
    CMD wget --no-verbose --tries=1 --spider http://localhost:80/nginx_health || exit 1

CMD ["nginx", "-g", "daemon off;"]
```

### Dashboard

```dockerfile
# dashboard/Dockerfile
FROM node:20-alpine AS builder

WORKDIR /app
COPY package*.json ./
RUN npm ci

COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf

EXPOSE 80

HEALTHCHECK --interval=10s --timeout=3s --start-period=5s --retries=3 \
    CMD wget --no-verbose --tries=1 --spider http://localhost:80 || exit 1

CMD ["nginx", "-g", "daemon off;"]
```

## docker-compose Configuration

```yaml
# docker-compose.yml
version: '3.9'

services:
  # PostgreSQL Database
  postgres:
    image: postgres:15-alpine
    environment:
      POSTGRES_DB: id_generator
      POSTGRES_USER: app
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD:-changeme}
    volumes:
      - postgres_data:/var/lib/postgresql/data
      - ./postgres/init.sql:/docker-entrypoint-initdb.d/01-schema.sql:ro
    ports:
      - "5432:5432"
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U app -d id_generator"]
      interval: 10s
      timeout: 5s
      retries: 5
    networks:
      - id-generator-net

  # Generator Instance 1
  generator-1:
    build:
      context: ./generator
      dockerfile: Dockerfile
    environment:
      DATACENTER_ID: 1
      MACHINE_ID: 1
      POSTGRES_DSN: postgresql://app:${POSTGRES_PASSWORD:-changeme}@postgres:5432/id_generator
      PERSISTENCE_ENABLED: ${PERSISTENCE_ENABLED:-true}
    ports:
      - "5001:5001"
    depends_on:
      postgres:
        condition: service_healthy
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:5001/health"]
      interval: 10s
      timeout: 5s
      retries: 3
    networks:
      - id-generator-net

  # Generator Instance 2
  generator-2:
    build:
      context: ./generator
      dockerfile: Dockerfile
    environment:
      DATACENTER_ID: 1
      MACHINE_ID: 2
      POSTGRES_DSN: postgresql://app:${POSTGRES_PASSWORD:-changeme}@postgres:5432/id_generator
      PERSISTENCE_ENABLED: ${PERSISTENCE_ENABLED:-true}
    ports:
      - "5002:5001"
    depends_on:
      postgres:
        condition: service_healthy
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:5001/health"]
      interval: 10s
      timeout: 5s
      retries: 3
    networks:
      - id-generator-net

  # Generator Instance 3
  generator-3:
    build:
      context: ./generator
      dockerfile: Dockerfile
    environment:
      DATACENTER_ID: 1
      MACHINE_ID: 3
      POSTGRES_DSN: postgresql://app:${POSTGRES_PASSWORD:-changeme}@postgres:5432/id_generator
      PERSISTENCE_ENABLED: ${PERSISTENCE_ENABLED:-true}
    ports:
      - "5003:5001"
    depends_on:
      postgres:
        condition: service_healthy
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:5001/health"]
      interval: 10s
      timeout: 5s
      retries: 3
    networks:
      - id-generator-net

  # nginx Load Balancer
  nginx:
    build:
      context: ./nginx
      dockerfile: Dockerfile
    ports:
      - "80:80"
    depends_on:
      - generator-1
      - generator-2
      - generator-3
    healthcheck:
      test: ["CMD", "wget", "--no-verbose", "--tries=1", "--spider", "http://localhost:80/nginx_health"]
      interval: 10s
      timeout: 5s
      retries: 3
    networks:
      - id-generator-net

  # Dashboard
  dashboard:
    build:
      context: ./dashboard
      dockerfile: Dockerfile
    environment:
      VITE_API_URL: http://localhost:80
    ports:
      - "3000:80"
    depends_on:
      - generator-1
      - generator-2
      - generator-3
    networks:
      - id-generator-net

networks:
  id-generator-net:
    driver: bridge

volumes:
  postgres_data:
```

## Environment Variables

### Generator Service

| Variable | Default | Required | Description |
|----------|---------|----------|-------------|
| DATACENTER_ID | 1 | Yes | Datacenter ID (0-31) |
| MACHINE_ID | 1 | Yes | Machine ID (0-31) |
| POSTGRES_DSN | - | Yes | PostgreSQL connection string |
| PERSISTENCE_ENABLED | true | No | Enable/disable persistence |
| LOG_LEVEL | INFO | No | Logging level |
| METRICS_ENABLED | true | No | Enable Prometheus metrics |

### PostgreSQL

| Variable | Default | Required | Description |
|----------|---------|----------|-------------|
| POSTGRES_DB | id_generator | Yes | Database name |
| POSTGRES_USER | app | Yes | Database user |
| POSTGRES_PASSWORD | changeme | Yes | Database password |

### Dashboard

| Variable | Default | Required | Description |
|----------|---------|----------|-------------|
| VITE_API_URL | http://localhost:80 | Yes | Backend API URL |

## Resource Requirements

### CPU and Memory

| Service | CPU | Memory | Disk |
|---------|-----|--------|------|
| postgres | 1 core | 512MB | 10GB |
| generator-1 | 0.5 core | 128MB | 100MB |
| generator-2 | 0.5 core | 128MB | 100MB |
| generator-3 | 0.5 core | 128MB | 100MB |
| nginx | 0.1 core | 64MB | 100MB |
| dashboard | 0.5 core | 256MB | 200MB |
| **Total** | **3.1 cores** | **~1.2 GB** | **~11 GB** |

### Resource Limits (docker-compose)

```yaml
services:
  generator-1:
    deploy:
      resources:
        limits:
          cpus: '0.5'
          memory: 256M
        reservations:
          cpus: '0.25'
          memory: 128M
```

## Deployment Commands

### Local Development

```bash
# Build and start all services
docker-compose up --build

# Start in background
docker-compose up -d --build

# View logs
docker-compose logs -f

# Scale generators
docker-compose up -d --scale generator=5

# Stop all services
docker-compose down

# Clean up volumes
docker-compose down -v
```

### Production Deployment

```bash
# Build images
docker-compose -f docker-compose.yml build

# Tag for registry
docker tag id_generator_nginx myregistry/id-generator-nginx:latest
docker tag id_generator_generator-1 myregistry/id-generator-generator:latest

# Push to registry
docker push myregistry/id-generator-nginx:latest
docker push myregistry/id-generator-generator:latest

# Deploy
docker-compose -f production.yml up -d
```
