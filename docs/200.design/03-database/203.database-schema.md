# Phase 203 — Database Schema

## Overview
This document defines the PostgreSQL database schema, migrations, and connection pooling configuration for the Unique ID Generator persistence layer.

## Schema Design

### DDL

```sql
-- Migration: 001_initial_schema.sql

-- Enable UUID extension (optional, for future use)
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

-- Main table for storing generated IDs
CREATE TABLE IF NOT EXISTS generated_ids (
    -- 64-bit Snowflake ID (primary key)
    id BIGINT PRIMARY KEY,

    -- Timestamp extracted from ID (for efficient time-based queries)
    timestamp_ms BIGINT NOT NULL,

    -- Datacenter identifier (0-31)
    datacenter_id SMALLINT NOT NULL
        CHECK (datacenter_id BETWEEN 0 AND 31),

    -- Machine identifier within datacenter (0-31)
    machine_id SMALLINT NOT NULL
        CHECK (machine_id BETWEEN 0 AND 31),

    -- Sequence number at time of generation (0-4095)
    sequence_num SMALLINT NOT NULL
        CHECK (sequence_num BETWEEN 0 AND 4095),

    -- Wall-clock time when record was inserted
    generated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),

    -- Optional metadata as JSONB
    metadata JSONB DEFAULT '{}'
);

-- Index for time-based queries (descending order for recent first)
CREATE INDEX idx_generated_ids_timestamp
    ON generated_ids(timestamp_ms DESC);

-- Index for datacenter/machine queries
CREATE INDEX idx_generated_ids_datacenter_machine
    ON generated_ids(datacenter_id, machine_id);

-- Index for generated_at queries
CREATE INDEX idx_generated_ids_generated_at
    ON generated_ids(generated_at DESC);

-- Composite index for time-range + datacenter queries
CREATE INDEX idx_generated_ids_timestamp_datacenter
    ON generated_ids(timestamp_ms DESC, datacenter_id);
```

## Schema Validation

### Constraints

| Constraint | Type | Validation |
|-----------|------|-----------|
| id PRIMARY KEY | UNIQUE | Must be unique 64-bit integer |
| datacenter_id | CHECK | 0 ≤ value ≤ 31 |
| machine_id | CHECK | 0 ≤ value ≤ 31 |
| sequence_num | CHECK | 0 ≤ value ≤ 4095 |
| generated_at | DEFAULT | Auto-set to NOW() |
| metadata | DEFAULT | Empty JSON object if null |

### Index Usage

| Query | Index Used |
|-------|------------|
| `SELECT * WHERE id = ?` | PRIMARY KEY |
| `SELECT * ORDER BY timestamp_ms DESC LIMIT 100` | idx_generated_ids_timestamp |
| `SELECT * WHERE datacenter_id = 1` | idx_generated_ids_datacenter_machine |
| `SELECT * WHERE generated_at > '2026-01-01'` | idx_generated_ids_generated_at |

## Connection Pooling

### asyncpg Configuration

```python
# Connection pool settings
POOL_CONFIG = {
    'min_size': 2,      # Keep 2 connections ready
    'max_size': 10,     # Cap at 10 connections
    'command_timeout': 30,  # Query timeout (seconds)
    'max_queries': 50000,   # Recycle connection after N queries
    'max_inactive_connection_lifetime': 300,  # Close stale after 5 min
}

# Pool sizing formula
"""
For 10,000 RPS with batch_size=100:
- DB writes per second = 10,000 / 100 = 100
- Each write holds connection for ~1ms
- Concurrent writes = 100 * 0.001 = 0.1
- With margin: pool_size = 10 is sufficient
"""
```

### Queue Worker

```python
# src/generator/infrastructure/persistence/async_queue.py
import asyncio
from typing import Optional
from dataclasses import dataclass

@dataclass
class IdRecord:
    id: int
    timestamp_ms: int
    datacenter_id: int
    machine_id: int
    sequence: int
    metadata: Optional[dict] = None

class AsyncWriteQueue:
    def __init__(
        self,
        repository,
        batch_size: int = 100,
        batch_timeout: float = 0.01,
        max_queue_size: int = 10000,
    ):
        self._repository = repository
        self._batch_size = batch_size
        self._batch_timeout = batch_timeout
        self._queue: asyncio.Queue = asyncio.Queue(maxsize=max_queue_size)
        self._worker_task: Optional[asyncio.Task] = None
        self._running = False

    async def start(self):
        self._running = True
        self._worker_task = asyncio.create_task(self._worker())

    async def stop(self):
        self._running = False
        if self._worker_task:
            await self._worker_task

    async def enqueue(self, record: IdRecord):
        try:
            self._queue.put_nowait(record)
        except asyncio.QueueFull:
            logger.warning("Persistence queue full, dropping record")

    async def _worker(self):
        batch = []
        while self._running:
            try:
                record = await asyncio.wait_for(
                    self._queue.get(),
                    timeout=self._batch_timeout
                )
                batch.append(record)

                if len(batch) >= self._batch_size:
                    await self._flush(batch)
                    batch = []
            except asyncio.TimeoutError:
                if batch:
                    await self._flush(batch)
                    batch = []

    async def _flush(self, batch: list):
        try:
            for record in batch:
                await self._repository.persist(record)
        except Exception as e:
            logger.error(f"Batch flush failed: {e}")
            # Re-queue failed items
            for record in batch:
                try:
                    self._queue.put_nowait(record)
                except asyncio.QueueFull:
                    pass
```

## Backup Strategy

### Daily Backup Script

```bash
#!/bin/bash
# scripts/backup.sh

DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR=/backups/postgres
CONTAINER=id_generator_postgres_1

# Create backup directory
mkdir -p $BACKUP_DIR

# Full backup
docker exec $CONTAINER pg_dump -U app -d id_generator \
    -F c -f /tmp/backup_$DATE.dump

# Copy to host
docker cp $CONTAINER:/tmp/backup_$DATE.dump $BACKUP_DIR/

# Keep last 7 days
find $BACKUP_DIR -name "backup_*.dump" -mtime +7 -delete
```

### Cron Schedule

```cron
# Daily backup at 2 AM
0 2 * * * /app/scripts/backup.sh
```
