# Ubiquitous Language

## Overview
This document establishes the shared vocabulary for the Unique ID Generator Distributed project. All team members, stakeholders, and systems must use these terms consistently.

## Domain Glossary

### Core Terms

| Term | Definition | Synonyms | Context |
|------|------------|----------|---------|
| **Unique ID** | A 64-bit unsigned integer that is globally unique and time-ordered. Generated using the Snowflake algorithm. | Snowflake ID, Distributed ID, Global ID | ID Generation |
| **Snowflake ID** | 64-bit ID with specific bit layout: sign(1) + timestamp(41) + datacenter(5) + machine(5) + sequence(12) | Unique ID, Distributed ID | ID Generation |
| **Timestamp** | Milliseconds since epoch (Twitter Snowflake epoch: 1288834974657, Nov 04, 2010) | TS, Time Component | ID Generation |
| **Datacenter ID** | 5-bit identifier (0-31) assigned per datacenter | DC ID, Datacenter Identifier | ID Generation |
| **Machine ID** | 5-bit identifier (0-31) assigned per machine within a datacenter | Node ID, Worker ID, Host ID | ID Generation |
| **Sequence Number** | 12-bit counter (0-4095) that resets to 0 every millisecond per machine | Seq, Counter, Sequence | ID Generation |
| **Epoch** | Reference timestamp used as starting point for timestamp component. Twitter Snowflake epoch: 1288834974657 (Nov 04, 2010 01:42:54.657 UTC) | Reference Time, Base Time | ID Generation |

### Service Terms

| Term | Definition | Synonyms | Context |
|------|------------|----------|---------|
| **Generator Service** | Python service that produces unique IDs using the Snowflake algorithm | ID Service, Generator, ID Generator | ID Generation |
| **Load Balancer** | nginx instance that distributes incoming requests across generator instances | LB, Reverse Proxy, nginx | Infrastructure |
| **Client** | Any internal service that calls the ID generation API | Consumer, Caller, Upstream Service | Client Interface |
| **Upstream** | Backend service that handles client requests (nginx terminology) | Backend | Infrastructure |
| **Instance** | A single running copy of a service (e.g., Generator Instance 1) | Node, Worker, Pod | Infrastructure |

### Database Terms

| Term | Definition | Synonyms | Context |
|------|------------|----------|---------|
| **Generated ID Record** | A row in the PostgreSQL database representing a generated ID | ID Record, Audit Log Entry | Persistence |
| **Audit Log** | Record of generated IDs for traceability and auditing purposes | ID Log, Persistence Log | Persistence |

### Monitoring Terms

| Term | Definition | Synonyms | Context |
|------|------------|----------|---------|
| **Health Status** | Current operational state of a generator instance (ok, degraded, down) | Instance Status, Service Health | Monitoring |
| **Instance ID** | Unique identifier for a generator instance (format: dc-{XX}-machine-{YY}) | Instance Identifier, Node ID | Monitoring |
| **Uptime** | Duration since an instance started | Service Uptime | Monitoring |
| **IDs Generated Counter** | Total count of IDs generated by an instance | ID Counter, Generation Counter | Monitoring |

### Error Terms

| Term | Definition | Synonyms | Context |
|------|------------|----------|---------|
| **Clock Backwards** | Error condition when system clock goes backwards in time | Clock Regression, Time Rollback | Error Handling |
| **Sequence Overflow** | Error condition when sequence exceeds 4095 (too many IDs in 1ms) | Sequence Exceeded, Counter Overflow | Error Handling |
| **Generator Unavailable** | Error condition when all generator instances are down | Service Unavailable, No Generators | Error Handling |

## Usage Guidelines

### Correct Usage
```markdown
- "The generator creates a Snowflake ID with timestamp 1288834974657"
- "Each datacenter has a unique Datacenter ID (0-31)"
- "The sequence number resets every millisecond"
- "Client services request IDs via the /generate endpoint"
```

### Incorrect Usage
```markdown
- ❌ "The machine generates a UUID" → UUIDs are 128-bit; our IDs are 64-bit Snowflake
- ❌ "The worker creates an ID" → Use "generator" or "service"
- ❌ "The datacenter creates IDs" → Datacenters don't create IDs; generators do
```

## Anti-Patterns: Conflicting Terms

| Term A | Term B | Conflict Resolution |
|--------|--------|---------------------|
| Machine ID | Node ID | Use "Machine ID" to avoid confusion with Kubernetes Node |
| Sequence | Counter | Use "Sequence Number" or "Sequence" |
| Instance | Pod | Use "Instance" for clarity; Pod is Kubernetes-specific |
