# Error Handling Specification

## Overview
This document defines the complete error taxonomy, error codes, response formats, and handling flows for the Unique ID Generator service.

## Error Taxonomy

### Error Categories

| Category | HTTP Code | Description | Trigger |
|----------|-----------|-------------|---------|
| Client Error | 400 | Malformed request | Invalid request format |
| Internal Error | 500 | Generator failure | Clock issue, system error |
| Unavailable | 503 | All generators down | nginx upstream unavailable |
| Timeout | 504 | Request timeout | Upstream timeout |

## Error Codes

| Code | HTTP Status | Description | Retry? | Severity |
|------|-------------|-------------|--------|----------|
| INTERNAL_ERROR | 500 | Unexpected internal error | No | HIGH |
| CLOCK_BACKWARDS | 500 | Clock went backwards in time | No | CRITICAL |
| SEQUENCE_OVERFLOW | 500 | Too many requests in 1ms | No | HIGH |
| GENERATORS_UNAVAILABLE | 503 | All instances down | Yes | CRITICAL |
| REQUEST_TIMEOUT | 504 | Request exceeded timeout | Yes | MEDIUM |
| DATABASE_ERROR | 500 | Database write failure | No | MEDIUM |

## Error Response Format

All error responses follow this JSON structure:

```json
{
  "error": "Human-readable error message",
  "code": "MACHINE_READABLE_CODE",
  "details": "Optional additional debugging information",
  "retry_after_ms": 1000
}
```

### Field Definitions

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| error | string | Yes | Human-readable message describing the error |
| code | string | Yes | Machine-readable error code from the table above |
| details | string | No | Additional debugging information |
| retry_after_ms | integer | No | Suggested retry delay in milliseconds |

## Error Handling Flows

### Flow 1: Single Generator Failure

```
Client                    nginx                    Generator 1              Generator 2
  │                        │                          │                        │
  │──── GET /generate ────▶│                          │                        │
  │                        │──── GET /generate ──────▶│                        │
  │                        │                          │ (DOWN)                 │
  │                        │                          │✗ Connection refused    │
  │                        │                          │                        │
  │                        │──── GET /generate ──────────────────────────────▶│
  │                        │                          │                        │ (OK)
  │                        │                          │                        │◀─── ID ─────
  │                        │◀─── ID ───────────────────────────────────────────
  │◀─── {"id": ...} ────│                          │                        │
```

**nginx Configuration:**
```nginx
upstream generators {
    server generator-1:5001;
    server generator-2:5002;
    server generator-3:5003;
}
```

### Flow 2: All Generators Down

```
Client                    nginx                    Generator 1,2,3
  │                        │                          │
  │──── GET /generate ────▶│                          │
  │                        │──── GET /generate ──────▶│ (all failing)
  │                        │                          │✗
  │                        │◀── 503 ──────────────────
  │◀── 503 {"code": "GENERATORS_UNAVAILABLE"} ───│
```

**nginx Configuration for All Down:**
```nginx
server {
    listen 80;

    location / {
        proxy_pass http://generators;
        proxy_connect_timeout 5s;
        proxy_read_timeout 10s;
    }

    # Return 503 when all upstream servers are down
    proxy_next_upstream error timeout;
    proxy_next_upstream_tries 3;
}
```

### Flow 3: Clock Going Backwards

```
Generator Service
      │
      │ get_current_timestamp_ms() returns 1288834974000
      │ last_timestamp_ms = 1288834974657
      │
      ▼
┌─────────────────┐
│ current < last? │
└────────┬────────┘
         │
         │ YES (drift = 657ms > 10ms threshold)
         ▼
┌─────────────────────────────────────┐
│ Log CRITICAL: Clock went backwards  │
│ Alert ops team                      │
│ Return HTTP 500 with CLOCK_BACKWARDS│
└─────────────────────────────────────┘
```

**Generator Code:**
```python
async def generate_id():
    current_ms = await get_current_timestamp_ms()
    
    if current_ms < self.last_timestamp_ms:
        drift = self.last_timestamp_ms - current_ms
        if drift > 10:
            logger.critical(f"Clock backwards by {drift}ms")
            raise ClockBackwardsError(f"Clock went backwards by {drift}ms")
        else:
            logger.warning(f"Clock drift: {drift}ms")
    
    # Continue with generation...
```

### Flow 4: Sequence Overflow

```
Generator Service
      │
      │ current_ms = last_timestamp_ms
      │ sequence = 4095 (max)
      │ sequence += 1 → 4096 >= 4096
      │
      ▼
┌──────────────────────┐
│ sequence >= 4096?    │
└──────────┬───────────┘
           │
           │ YES
           ▼
┌──────────────────────────────────────┐
│ while current_ms == last_timestamp_ms │
│     current_ms = get_timestamp()      │
│ sequence = 0                          │
│ Continue with generation              │
└──────────────────────────────────────┘
```

**Generator Code:**
```python
async def generate_id():
    current_ms = await get_current_timestamp_ms()
    
    if current_ms == self.last_timestamp_ms:
        self.sequence += 1
        if self.sequence >= 4096:
            # Wait for next millisecond
            while current_ms == self.last_timestamp_ms:
                current_ms = await get_current_timestamp_ms()
            self.sequence = 0
    else:
        self.sequence = 0
    
    self.last_timestamp_ms = current_ms
    return self._build_id(current_ms, self.sequence)
```

### Flow 5: Request Timeout

```
Client                    nginx                    Generator
  │                        │                          │
  │──── GET /generate ────▶│                          │
  │                        │──── GET /generate ──────▶│
  │                        │                          │ (slow response)
  │                        │                          │ ✗ TIMEOUT (10s)
  │                        │◀── 504 ──────────────────
  │◀── 504 {"code": "REQUEST_TIMEOUT"} ───│
```

**nginx Timeout Configuration:**
```nginx
location / {
    proxy_pass http://generators;
    proxy_connect_timeout 5s;
    proxy_send_timeout 10s;
    proxy_read_timeout 10s;
}
```

## Alerting Strategy

| Error | Severity | Action | Notification |
|-------|----------|--------|--------------|
| CLOCK_BACKWARDS | CRITICAL | Page ops immediately | PagerDuty |
| All generators down | CRITICAL | Page ops immediately | PagerDuty |
| Sequence overflow | HIGH | Alert during business hours | Slack |
| Database unavailable | MEDIUM | Alert during business hours | Slack |
| Request timeout | LOW | Log and monitor | Dashboard |

## Error Log Format

All errors must be logged with the following structure:

```json
{
  "timestamp": "2026-09-29T12:00:00.000Z",
  "level": "ERROR",
  "correlation_id": "uuid-v4",
  "instance_id": "dc-01-machine-01",
  "error_code": "CLOCK_BACKWARDS",
  "message": "Clock went backwards",
  "details": {
    "current_ms": 1288834974000,
    "last_ms": 1288834974657,
    "drift_ms": 657
  }
}
```

## Testing Error Handling

| Scenario | Test Method | Expected Result |
|---------|-------------|-----------------|
| Single generator down | Kill one generator | Requests route to healthy generators |
| All generators down | Kill all generators | Return 503 GENERATORS_UNAVAILABLE |
| Clock backwards | Mock clock | Return 500 CLOCK_BACKWARDS |
| Sequence overflow | Burst test | Wait for next ms, return ID |
| Request timeout | Slow generator | Return 504 after timeout |
