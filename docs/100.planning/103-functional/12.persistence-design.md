# Persistence Design

## Overview
This document specifies the PostgreSQL persistence design for storing generated IDs, including schema, async write patterns, and graceful degradation.

## Persistence Requirements

| Requirement | Value |
|-------------|-------|
| Purpose | Audit trail and traceability |
| Blocking | Async (non-blocking) |
| Schema | Single table |
| Connection pooling | Yes (asyncpg) |

---

## Database Schema

### DDL

```sql
CREATE TABLE IF NOT EXISTS generated_ids (
    id BIGINT PRIMARY KEY,
    timestamp_ms BIGINT NOT NULL,
    datacenter_id SMALLINT NOT NULL,
    machine_id SMALLINT NOT NULL,
    sequence_num SMALLINT NOT NULL,
    generated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    metadata JSONB
);

-- Index for time-based queries
CREATE INDEX idx_generated_ids_timestamp
    ON generated_ids(timestamp_ms DESC);

-- Index for datacenter/machine queries
CREATE INDEX idx_generated_ids_datacenter_machine
    ON generated_ids(datacenter_id, machine_id);

-- Index for time-based queries with datacenter
CREATE INDEX idx_generated_ids_generated_at
    ON generated_ids(generated_at DESC);
```

### Constraints

| Constraint | Type | Purpose |
|-----------|------|---------|
| id PRIMARY KEY | UNIQUE | Prevent duplicates |
| timestamp_ms NOT NULL | CHECK | Ensure timestamp exists |
| datacenter_id CHECK | CHECK (0-31) | Validate datacenter |
| machine_id CHECK | CHECK (0-31) | Validate machine |
| sequence_num CHECK | CHECK (0-4095) | Validate sequence |

## Async Write Design

### Architecture

```
┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│   Generator   │ ───▶ │  Async Queue │ ───▶ │  Batch Worker │
│   Service     │      │  (in-memory) │      │  (background) │
└──────────────┘      └──────────────┘      └───────┬──────┘
                                                       │
                                                       ▼
                                             ┌──────────────┐
                                             │  PostgreSQL  │
                                             │  (batched)   │
                                             └──────────────┘
```

### Implementation

```python
import asyncio
from dataclasses import dataclass
from typing import Optional
import asyncpg

@dataclass
class IdRecord:
    id: int
    timestamp_ms: int
    datacenter_id: int
    machine_id: int
    sequence: int
    metadata: Optional[dict] = None

class AsyncIdRepository:
    def __init__(
        self,
        dsn: str,
        batch_size: int = 100,
        max_queue_size: int = 10000,
    ):
        self.dsn = dsn
        self.batch_size = batch_size
        self.max_queue_size = max_queue_size
        self._queue: asyncio.Queue = asyncio.Queue(maxsize=max_queue_size)
        self._pool: Optional[asyncpg.Pool] = None
        self._worker_task: Optional[asyncio.Task] = None
        self._running = False

    async def connect(self):
        """Initialize connection pool."""
        self._pool = await asyncpg.create_pool(
            self.dsn,
            min_size=2,
            max_size=10,
        )
        self._running = True
        self._worker_task = asyncio.create_task(self._worker())

    async def close(self):
        """Gracefully shutdown."""
        self._running = False
        if self._worker_task:
            await self._worker_task
        if self._pool:
            await self._pool.close()

    async def persist(self, record: IdRecord):
        """Non-blocking persist to queue."""
        try:
            self._queue.put_nowait(record)
        except asyncio.QueueFull:
            logger.warning("Persistence queue full, dropping record")
            # Don't block - IDs still generated

    async def _worker(self):
        """Background worker that batches writes."""
        batch = []

        while self._running:
            try:
                # Wait for items or timeout
                record = await asyncio.wait_for(
                    self._queue.get(),
                    timeout=0.01  # 10ms batch window
                )
                batch.append(record)

                # Flush if batch full
                if len(batch) >= self.batch_size:
                    await self._flush(batch)
                    batch = []

            except asyncio.TimeoutError:
                # Flush any pending
                if batch:
                    await self._flush(batch)
                    batch = []

    async def _flush(self, batch: list):
        """Flush batch to database."""
        if not batch:
            return

        try:
            async with self._pool.acquire() as conn:
                await conn.executemany("""
                    INSERT INTO generated_ids
                    (id, timestamp_ms, datacenter_id, machine_id, sequence_num, metadata)
                    VALUES ($1, $2, $3, $4, $5, $6)
                    ON CONFLICT (id) DO NOTHING
                """, [
                    (r.id, r.timestamp_ms, r.datacenter_id,
                     r.machine_id, r.sequence, r.metadata)
                    for r in batch
                ])
        except Exception as e:
            logger.error(f"Batch flush failed: {e}")
            # Re-queue failed items
            for record in batch:
                try:
                    self._queue.put_nowait(record)
                except asyncio.QueueFull:
                    pass
```

## Graceful Degradation

### State Machine

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  AVAILABLE  │ ──▶ │  DEGRADED   │ ──▶ │  UNAVAILABLE│
└─────────────┘     └─────────────┘     └─────────────┘
       ▲                   ▲                   │
       │                   │                   │
       └───────────────────┴───────────────────┘
                    Recovery
```

### Behavior by State

| State | Write Behavior | Read Behavior |
|-------|---------------|---------------|
| AVAILABLE | Async write | N/A |
| DEGRADED | Log warning, drop writes | N/A |
| UNAVAILABLE | Skip silently | N/A |

### Implementation

```python
class RepositoryState:
    AVAILABLE = "available"
    DEGRADED = "degraded"
    UNAVAILABLE = "unavailable"

class DegradableRepository:
    def __init__(self):
        self._state = RepositoryState.AVAILABLE
        self._consecutive_failures = 0

    async def persist(self, record: IdRecord):
        if self._state == RepositoryState.UNAVAILABLE:
            return  # Silently skip

        try:
            await self._repository.persist(record)
            self._consecutive_failures = 0
            if self._state != RepositoryState.AVAILABLE:
                self._state = RepositoryState.AVAILABLE
                logger.info("Database connection restored")

        except Exception as e:
            self._consecutive_failures += 1
            if self._consecutive_failures >= 3:
                self._state = RepositoryState.DEGRADED
                logger.warning(f"Database degraded: {e}")

            if self._consecutive_failures >= 10:
                self._state = RepositoryState.UNAVAILABLE
                logger.error(f"Database unavailable: {e}")
```

## Connection Pooling

### Pool Configuration

| Parameter | Value | Rationale |
|-----------|-------|-----------|
| min_size | 2 | Keep 2 connections ready |
| max_size | 10 | Cap for 10K RPS |
| command_timeout | 30s | Query timeout |
| max_queries | 50000 | Recycle connections |
| max_inactive_connection_lifetime | 300s | Close stale connections |

### Pool Sizing Formula

```
For 10,000 RPS with batch_size=100:
- Queries per second = 10,000 / 100 = 100
- Each query holds connection for ~1ms
- Pool size = 100 concurrent * 0.001s * 10,000 RPS / 1000 = 1
- Safety margin: pool_size = 10
```

## Query Patterns

### Common Queries

**Count IDs by generator:**
```sql
SELECT datacenter_id, machine_id, COUNT(*)
FROM generated_ids
GROUP BY datacenter_id, machine_id;
```

**IDs generated in time range:**
```sql
SELECT * FROM generated_ids
WHERE generated_at BETWEEN '2026-09-01' AND '2026-09-29'
ORDER BY generated_at DESC
LIMIT 100;
```

**Verify no duplicates:**
```sql
SELECT id, COUNT(*) as cnt
FROM generated_ids
GROUP BY id
HAVING COUNT(*) > 1;
```
