# API Contracts

## Overview
This document provides detailed API specifications for the Unique ID Generator service, expanding on the OpenAPI contract defined in `contracts/openapi.yaml`.

## Endpoints

### GET /generate

Generate a unique 64-bit ID using the Snowflake algorithm.

| Property | Value |
|----------|-------|
| Method | GET |
| Path | /generate |
| Content-Type | application/json |
| Response Code | 200 (success), 500 (error), 503 (unavailable) |
| Timeout | 5 seconds |

**Request:** No parameters required

**Success Response (200):**
```json
{
  "id": 1825478541164436481
}
```

**Error Response (500 - Internal Error):**
```json
{
  "error": "Clock went backwards",
  "code": "CLOCK_BACKWARDS"
}
```

**Error Response (503 - Service Unavailable):**
```json
{
  "error": "No generators available",
  "code": "GENERATORS_UNAVAILABLE",
  "retry_after_ms": 1000
}
```

**Response Headers:**
```
Content-Type: application/json
X-Request-ID: <correlation-id>
```

### GET /health

Health check endpoint for monitoring and load balancer health checks.

| Property | Value |
|----------|-------|
| Method | GET |
| Path | /health |
| Content-Type | application/json |
| Response Code | 200 (healthy), 503 (unhealthy) |

**Success Response (200):**
```json
{
  "status": "ok",
  "instance": "dc-01-machine-03",
  "uptime_seconds": 86400,
  "ids_generated": 1234567890
}
```

**Degraded Response (200):**
```json
{
  "status": "degraded",
  "instance": "dc-01-machine-03",
  "uptime_seconds": 86400,
  "ids_generated": 1234567890,
  "warning": "Clock drift detected: 2ms"
}
```

**Unhealthy Response (503):**
```json
{
  "status": "down",
  "instance": "dc-01-machine-03",
  "error": "Clock synchronization lost"
}
```

### GET /metrics

Prometheus-compatible metrics endpoint.

| Property | Value |
|----------|-------|
| Method | GET |
| Path | /metrics |
| Content-Type | text/plain (Prometheus format) |
| Response Code | 200 |

**Response (Prometheus format):**
```
# HELP ids_generated_total Total number of IDs generated
# TYPE ids_generated_total counter
ids_generated_total{datacenter_id="1",machine_id="1"} 1234567890

# HELP request_duration_seconds HTTP request duration
# TYPE request_duration_seconds histogram
request_duration_seconds_bucket{le="0.005"} 1000
request_duration_seconds_bucket{le="0.01"} 5000
request_duration_seconds_bucket{le="0.05"} 10000
request_duration_seconds_bucket{le="+Inf"} 10000

# HELP generator_status Generator health status (0=down, 1=degraded, 2=ok)
# TYPE generator_status gauge
generator_status{instance="dc-01-machine-01"} 2
```

## Instance ID Format

All instance identifiers follow the format: `dc-{XX}-machine-{YY}`

| Component | Pattern | Example |
|-----------|---------|---------|
| Datacenter | `dc-{00-31}` | dc-01, dc-31 |
| Machine | `machine-{00-31}` | machine-01, machine-31 |
| Full | `dc-{XX}-machine-{YY}` | dc-01-machine-03 |

**Regex:** `^dc-(0[1-9]|1[0-9]|2[0-9]|3[0-1])-machine-(0[1-9]|1[0-9]|2[0-9]|3[0-1])$`

## HTTP Status Codes

| Code | Meaning | When Used |
|------|---------|-----------|
| 200 | OK | Successful response |
| 400 | Bad Request | Malformed request (unlikely for GET) |
| 500 | Internal Server Error | Generator failure (clock backwards, etc.) |
| 503 | Service Unavailable | All generators down or unhealthy |
| 504 | Gateway Timeout | Request timeout |
