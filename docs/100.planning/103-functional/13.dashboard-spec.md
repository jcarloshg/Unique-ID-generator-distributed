# Health Dashboard Specification

## Overview
This document specifies the Vite-based health monitoring dashboard for the Unique ID Generator service.

## Dashboard Requirements

### Features

| Feature | Priority | Description |
|---------|----------|-------------|
| Instance Status | P0 | Show health of each generator |
| ID Counter | P1 | Display total IDs generated |
| Uptime Display | P1 | Show instance uptime |
| Error Count | P2 | Display error counts |
| Request Latency | P2 | Show P50/P95/P99 latency |

---

## Technical Stack

| Component | Technology | Rationale |
|-----------|------------|-----------|
| Framework | Vite + React 18 | Fast dev, modern tooling |
| Language | TypeScript | Type safety |
| Data Fetching | TanStack Query | Caching, polling |
| Styling | TailwindCSS | Rapid UI development |
| Charts | Recharts | Simple charting |
| State | Zustand | Lightweight state |

---

## Dashboard API Integration

### Data Sources

| Endpoint | Data | Polling Interval |
|----------|------|-----------------|
| GET /health | Instance status, uptime, IDs generated | 5 seconds |
| GET /metrics | Prometheus metrics | 10 seconds |

### Health Response Type

```typescript
interface HealthResponse {
  status: 'ok' | 'degraded' | 'down';
  instance: string;  // "dc-01-machine-03"
  uptime_seconds: number;
  ids_generated: number;
  warning?: string;
  error?: string;
}
```

### Metrics Response Type

```typescript
interface MetricsResponse {
  ids_generated_total: number;
  request_duration_seconds_p50: number;
  request_duration_seconds_p95: number;
  request_duration_seconds_p99: number;
  error_total: number;
}
```

## Key Components

### SystemStatus

```tsx
interface SystemStatusProps {
  healthy: number;
  total: number;
  isLoading: boolean;
}

const SystemStatus: React.FC<SystemStatusProps> = ({ healthy, total, isLoading }) => {
  const status = healthy === total ? 'healthy' : healthy > 0 ? 'partial' : 'down';
  const color = status === 'healthy' ? 'green' : status === 'partial' ? 'yellow' : 'red';

  return (
    <div className="flex items-center gap-2">
      <span className={`text-${color}-500`}>●</span>
      <span>
        {status === 'healthy' && `Healthy (${healthy}/${total})`}
        {status === 'partial' && `Degraded (${healthy}/${total})`}
        {status === 'down' && `Down (${healthy}/${total})`}
      </span>
    </div>
  );
};
```

### InstanceTable

```tsx
interface Instance {
  instance: string;
  status: 'ok' | 'degraded' | 'down';
  uptime_seconds: number;
  ids_generated: number;
  error_count?: number;
}

const InstanceTable: React.FC<{ instances: Instance[] }> = ({ instances }) => {
  return (
    <table className="min-w-full">
      <thead>
        <tr>
          <th>Instance</th>
          <th>Status</th>
          <th>Uptime</th>
          <th>IDs Generated</th>
          <th>Errors</th>
        </tr>
      </thead>
      <tbody>
        {instances.map((inst) => (
          <tr key={inst.instance}>
            <td>{inst.instance}</td>
            <td><StatusBadge status={inst.status} /></td>
            <td>{formatUptime(inst.uptime_seconds)}</td>
            <td>{formatNumber(inst.ids_generated)}</td>
            <td>{inst.error_count ?? 0}</td>
          </tr>
        ))}
      </tbody>
    </table>
  );
};
```

## Polling Strategy

### Configuration

| Metric | Polling Interval | Timeout | Retry |
|--------|-----------------|---------|-------|
| Instance status | 5 seconds | 3 seconds | 3 retries |
| Metrics | 10 seconds | 5 seconds | 3 retries |

### Implementation

```typescript
const { data: healthData } = useQuery({
  queryKey: ['health'],
  queryFn: () => fetch('/health').then(r => r.json()),
  refetchInterval: 5000,
  retry: 3,
  staleTime: 2000,
});

const { data: metricsData } = useQuery({
  queryKey: ['metrics'],
  queryFn: () => fetch('/metrics').then(r => r.text()),
  refetchInterval: 10000,
  retry: 3,
  staleTime: 5000,
});
```

## Deployment

### Dockerfile

```dockerfile
FROM node:20-alpine AS builder

WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

### docker-compose

```yaml
dashboard:
  build: ./dashboard
  ports:
    - "3000:80"
  environment:
    - VITE_API_URL=http://localhost:80
  depends_on:
    - nginx
```
